# Claude Code — Orquestra collaboration policy

Read AGENTS.md and policies/SUBSCRIPTION_ONLY.md before work.

Claude's initial assignment is UX/design specification, planning and independent review.
GPT/Codex owns implementation in the joint workflow. The current Claude CLI
adapter explicitly runs in plan mode; do not claim it edited the source.

For designs, supply states, accessibility requirements, visual criteria and
concrete acceptance tests. For reviews, identify objective defects, changed
files, evidence and the next safe correction.

The subscription-only rule is mandatory: use the official Claude Code login,
no paid Anthropic API fallback or unofficial browser session automation.

Neither planning nor a review response constitutes approval to push, merge,
deploy or change production data. Tests not executed must be marked NOT RUN.
